# Couch Launcher: working notes for Claude

Controller-first TV home screen for Steam games and Jellyfin. The spec is `docs/BRIEF.md` (source of truth).
After any context compaction, re-read `docs/BRIEF.md`, this file, `docs/DESIGN.md` and `docs/DECISIONS.md` before continuing.

## Commands

| Command | What it does |
| --- | --- |
| `bun install` | Install dependencies (Bun workspaces) |
| `bun run check` | The phase gate: biome lint+format, strict tsc, `bun test`, vite build, Playwright. Must be green before every commit. |
| `bun run check --no-e2e` | Same without Playwright, for the inner loop |
| `bun test` | Unit and API tests (TZ forced to UTC by `scripts/test-preload.ts`) |
| `bun run e2e` | Playwright UI tests (needs `bun run build:web` first; starts a mock server on :7790) |
| `bun run dev` | Service in mock mode on :7744 serving `apps/web/dist` |
| `bun run build` | Compile single executables for linux-x64 and windows-x64 into `out/` |
| `bun run fixtures` | Regenerate `fixtures/` (deterministic; commit the result) |
| `bun run format` | Apply biome formatting |

## Layout

- `packages/core` — item types, keys, picker scoring. Pure: no I/O, no Date.now, no platform checks.
- `apps/server` — Bun HTTP service. `src/platform/` is the only platform-specific code (`linux.ts`, `windows.ts`).
- `apps/web` — React + Vite + Tailwind UI. Focus engine and input in `src/focus` / `src/input`.
- `fixtures/` — synthetic Steam root and Jellyfin JSON, generated by `scripts/make-fixtures.ts`.
- `scripts/` — check, build, fixtures, install scripts, doctor wrapper.

## Conventions

- TypeScript strict everywhere, `noUncheckedIndexedAccess` on. Biome for lint and format (double quotes, semicolons, width 110).
- Import local files with the `.ts` extension.
- All side effects go through injected deps (`ReadFs`, `ProcessRunner`, `Clock`, `fetch`) so both platforms test on any host.
- Never write under the Steam root. Steam access goes through `ReadFs`, which has no write methods.
- Secrets (the Jellyfin API key) live only in config.toml. Never log, store or return them. The logger scrubs registered secrets.
- Build paths with `platform.path` (posix or win32), never string concatenation.
- No `process.platform` checks outside `apps/server/src/platform/index.ts`.
- Tests: `*.test.ts` for bun, `*.e2e.ts` for Playwright (so bun does not pick them up).
- Every decision where the brief is silent or wrong goes into `docs/DECISIONS.md` with a date.
- Commit and push at the end of every phase with `check` green; record acceptance evidence in `docs/DESIGN.md`.

## Environment variables

`COUCH_MOCK=1` (fixtures, recorded launches), `COUCH_NOW=<iso>` (pin clock), `COUCH_CONFIG_DIR`, `COUCH_DATA_DIR`, `COUCH_PORT`.
